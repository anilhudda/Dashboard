## Welcome! 🚗✨

This repository contains comprehensive documentation and templates for setting up a professional accounting system for your car fitness center business with 4 partners.

Sample transactions to test your setup:

Comprehensive pricing guide for car fitness center services:
- Basic services (wash, cleaning)

- Detailing packages
- Specialized services
- Membership tiers

- Profitability calculations

Google Sheets formula reference guide:
- Essential formulas for your accounting needs
- Common calculations (SUM, AVERAGE, COUNT)

- Specific use cases for car fitness center
- Troubleshooting tips

## 🆘 Troubleshooting

### Formulas Not Working?
- Check sheet names match exactly
- Verify cell references
- Look for #REF! or #NAME? errors
- See Quick_Reference_Formulas.md

### Data Entry Issues?
- Use dropdowns (data validation)
- Check date formats
- Verify currency format

### Charts Not Updating?
- Check chart data range
- Refresh the page
- Verify source data is correct

### Need More Help?
- Google Sheets Help Center: https://support.google.com/docs/
- Review the detailed setup instructions
- Consider hiring a bookkeeper for initial setup

## 🔐 Access & Security

### Sharing Your Google Sheet
1. Click "Share" (top right)
2. Add all 4 partners' email addresses
3. Set permissions:
   - All partners: "Editor" OR
   - Some partners: "Viewer" only
4. Consider: One person as "Owner"

### Protect Important Cells
- Protect formula cells from accidental edits
- Data → Protect sheets and ranges
- Allow partners to edit data entry cells only

### Backup Strategy
- Google automatically saves versions
- Export monthly reports as PDF
- Download Excel backup monthly
- Store receipts in Google Drive
